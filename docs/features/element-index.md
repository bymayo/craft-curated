# Element index column

Each Curated field is available as a **column option** on its host element's index (the Entries / Categories / Assets / Users index where the source element lives).

Add it like any other column: from the index, open the column settings (gear / customise) and enable the Curated field.

The column shows the **first curated item**, with a **"+N" overflow** indicating how many more are in the list — exactly like Craft's native relation field columns. It gives editors a quick read of what's curated on each source without opening it.
