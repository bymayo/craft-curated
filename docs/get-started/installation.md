# Installation

Curated installs like any other Craft plugin — via Composer or directly from the Plugin Store.

## Composer

```sh
composer require bymayo/curated
```

Then enable the plugin:

```sh
php craft plugin/install curated
```

Or enable it in the control panel under **Settings → Plugins**.

## Plugin Store

In the control panel, go to **Plugin Store**, search for **Curated**, and click **Install**.

## Next steps

- Check the [Requirements](requirements.md) if the install fails.
- Create your first field in [Setup](setup.md).
