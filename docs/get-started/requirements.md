# Requirements

Curated requires:

- **Craft CMS 5.7+**
- **PHP 8.2+**

## Commerce element types

The **Commerce Product** and **Commerce Variant** element types require [Craft Commerce](https://plugins.craftcms.com/commerce) to be installed and enabled. The other four element types (Entry, Category, Asset, User) have no extra dependencies.

See [Supported element types](../guides/supported-element-types.md) for the full list.
